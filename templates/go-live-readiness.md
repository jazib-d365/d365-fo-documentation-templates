# Go-live readiness checklist
| Gate | Owner | Evidence | Decision |
|---|---|---|---|
| Critical business acceptance tests completed | Business owners | Test report/build | |
| Blocking defects resolved and retested | Test lead | Defect report | |
| Residual risks explicitly accepted | Sponsor/process owners | Risk register | |
| Migration and opening positions reconciled | Data/finance owners | Reconciliation | |
| Roles and access validated | Security lead | Role tests | |
| Integrations and monitoring ready | Integration lead | SIT and alerts | |
| Cutover and recovery rehearsed | Cutover lead | Rehearsal report | |
| User training and SOPs ready | Training lead | Completion evidence | |
| Support ownership and escalation confirmed | Support lead | Roster and runbook | |
| Authorized go/no-go decision | Sponsor | Signed decision/build/scope | |

Record each gate as Ready, Not ready, or Approved exception with owner and mitigation. A checked box without evidence is not readiness.
