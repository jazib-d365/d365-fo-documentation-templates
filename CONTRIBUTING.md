# Contributing
Useful contributions include a reproducible scenario, a corrected expected result, a missing prerequisite, or a broken official documentation link.

1. Search existing issues.
2. Describe the business requirement and the affected file.
3. Include application version, relevant feature settings, prerequisites, steps, actual result, and expected result.
4. Submit a focused pull request with a reason for the change and how you validated it.

Use fictional account numbers and business data. Remove tenant URLs, credentials, personal information, and client documents from examples. Mark unexecuted scenarios as unexecuted. Keep links relative within each resource pack so the pack can be reused independently.

Publication here does not establish a reuse license for your contribution. Discuss licensing with the repository owner if you need permission to redistribute material.
